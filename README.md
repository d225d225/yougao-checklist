# 優高檢核表 — 永平高中優質化計畫・子計畫自主管理檢核表

組長每辦完一個活動，就把公文、獎狀、課表、簽到表、照片、心得上傳，AI 整理成檢核表的一列，
自動寫進 Google Drive「優高檢核專區/子計畫代碼/」裡的 Google 文件。

## 給組長的使用說明

1. 打開網址，輸入通關密碼。
2. 在頁首下方點選 **子計畫**（例如 A-學）。學年度會依日期自動判斷（8 月～隔年 7 月為一個學年度）。
3. **新增活動**：上傳這次活動的所有檔案（可多選；手機可直接拍照）→ 按「交給 AI 整理」→
   檢查並修改 AI 填的內容、勾選要放進檢核表的照片 →「確認寫入」。
   - AI 看不出來的欄位會標示「需要你補上」，不會亂編。
   - 學生姓名會自動遮罩成「胡*穎」。
4. **活動列表**：修改或刪除已登錄的活動，存檔後 Google 文件會自動重新產生。
5. **PLC 社群**：填社群成員和會議紀錄，也可以上傳簽到表讓 AI 擷取。
6. **年度彙整**：期末按「AI 依目前所有活動草擬」，產生經費規畫、質化／量化成效、檢討與修正、
   執行亮點、困難與總體評估，修改後按「儲存彙整」。
7. **總覽**：開啟 Google 文件，或下載 PDF／Word 繳交。

## 雲端資料夾結構

```
優高檢核專區/
├── reference/                 ← 空白檢核表（模板）與範例，App 只讀不寫
├── _config.json               ← 子計畫代碼清單
└── A-學/
    ├── 115_(A-學)永平高中優質化計畫自主管理檢核表     ← Google 文件，連結固定不變
    ├── data_115.json          ← 所有活動資料（換人、換電腦都能接續）
    └── 原始資料/
        └── 2026-09-20_凱比機器人比賽/ …
```

- 同一學年度再新增資料，會更新**同一份** Google 文件（連結不變）。
- 下一個學年度（8 月起）會產生新的一份（檔名開頭 116）。
- 活動超過 16 筆、照片超過 32 張時，多出來的會接在主表格後面的「（續）」表格。

## 技術架構

- `app.py`：Streamlit 網頁（秋楓樣式）
- `core/ai.py`：Claude API（讀檔用 claude-sonnet-5-5，年度彙整用 claude-opus-5-5，JSON schema 結構化輸出）
- `core/sheet.py`：把資料整理成檢核表內容
- `core/storage.py`：透過 Apps Script 讀寫 Google Drive；沒設定網址時改存本機 `local_data/`
- `apps_script/Code.gs`：在 Google 端建資料夾、存檔、依模板填寫 Google 文件

部署步驟見 [部署教學.md](部署教學.md)。
